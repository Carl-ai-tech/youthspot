# YouthScope — 年齡層對齊引擎

Spec §5 的可執行實作，**接的是真的政府資料**。這是專案的第一層（護城河），
前端與 AI 問答都建在它上面。

## 跑起來

```bash
python data/build_reference.py              # 抓政府資料，產出 reference_ntpc.json
python demo_align.py                        # 四幕 demo，對應 Demo 腳本 1:00–2:10
python data/backtest.py                     # 回測：拆組方法的實測誤差
python -m unittest discover -s tests -v     # 41 個測試
```

> Windows 上若 `python` 指到 Microsoft Store 的殼，用完整路徑：
> `%LOCALAPPDATA%\Programs\Python\Python312\python.exe`
> PowerShell 中文亂碼時先 `$env:PYTHONIOENCODING="utf-8"`

`reference_ntpc.json` 已進版控，所以 **clone 下來不連網也能直接 demo**。
要更新資料才需要跑 `build_reference.py --refresh`。

## 資料來源（全部免金鑰、免註冊）

| 來源 | 用途 | 粒度 |
|---|---|---|
| 內政部戶政司 [ODRP014](https://data.gov.tw/dataset/32973) 村里戶數、單一年齡人口 | P(a) 單一年齡人口 | **單一年齡**、村里別 |
| 主計總處 [mp04020](https://data.gov.tw/dataset/31827) 歷年年齡組別勞動力參與率 | r(a) 公式 B 的基底 | 五歲組、全國、1978– |
| 主計總處 mp04031 歷年年齡組別失業率 | 公式 D 借用的形狀 | 五歲組、全國、1978– |

兩個死穴（Spec §6.3）的現況：

- **死穴 1 單一年齡人口 — 解決。** 戶政司直接給到每一歲，新北市 1,039 個村里加總。
- **死穴 2 分齡發生率 — 七成解決。** 官方最細只到五歲組，18 歲的切點卡在
  15-19 組**內部**，且只有全國沒有分縣市。由 `data/ungroup.py` 拆組處理，
  組內分布是推估、**組間加總分毫不差等於官方公布值**（見下）。

## 檔案結構

```
engine/          純函式，不碰網路、不碰 LLM
  schema.py        AgeBand / MetricKind / Provenance / AlignedRecord  ← §7.3 協作介面
  reference.py     P(a)、r(a) 查表層；優先讀官方檔，沒有才退回示意檔
  align.py         公式 A / B / C / D 與信心度判定                    ← 核心
data/            唯一碰網路的一層
  sources.py       三個資料源的網址與抓取工具（含 _cache/）
  fetch_population.py  戶政司 → P(a)，自動找最新一期
  fetch_labour.py      主計總處 → 五歲組勞參率與失業率
  ungroup.py       五歲組 → 單一年齡（PCHIP + 組內校準）             ← 死穴 2 的解法
  backtest.py      量測拆組方法的實際誤差                          ← 信心度的證據
  build_reference.py   把三者組合成 reference_ntpc.json
  reference_ntpc.json  ✅ 官方資料（進版控，離線可用）
  reference_placeholder.json  示意數字，只剩測試在用
demo_align.py    現場 demo，畫面上每個數字都從資料算，沒有寫死
tests/           把「會被評審追問的性質」鎖住
```

## 拆組怎麼做的（會被問）

官方只公布「15-19 歲勞參率 9.68%」，我們要的是 18 歲那一格。做法兩步：

1. **形狀**：用組中點當節點跑 PCHIP（保單調三次 Hermite）。不用一般三次樣條，
   因為勞參率從 9.7% 衝到 62.8% 那一段，樣條會先掉到負值再彈回來。
2. **校準**：組內等比例縮放，讓加權平均**精確等於**官方公布值。
   勞參率用 P(a) 加權、失業率用 P(a)·勞參率(a) 加權（分母是勞動力不是人口）。

第 2 步是能不能上台的關鍵：**組內分布是我們推估的，組間加總是官方的**。
`tests/test_real_reference.py::test_official_band_totals_are_exact` 就是在鎖這條。

## 拆組準不準？我們測過（`data/backtest.py`）

把官方五歲組併成十歲組（假裝拿不到那麼細），用我們的方法拆回來，跟真值比：

| 曲線 | 我們的平均誤差 | 什麼都不做 | 結論 |
|---|---|---|---|
| 勞動力參與率 | **2.49pp** | 8.30pp | ✅ 誤差降到 30% |
| 失業率 | 0.76pp | 0.54pp | ❌ **比不做更差** |

失業率為什麼失敗：它在 20-24 歲有個高峰（15-19 是 9.21%、20-24 是 11.60%、
25-29 掉到 5.77%）。合併之後那個峰消失了，我們畫的平滑曲線把 15-19 硬拉高。
勞參率是單調上升的，就沒有這個問題。

**這個失敗有價值** —— 它給了一條有資料支持的信心度規則，見下。
回測本身也鎖成測試（`TestBacktest`），換資料後結論若改變會立刻知道。

## 信心度怎麼定的

三道檢查，任何一道不過就降級：

| 檢查 | 問什麼 | 沒過的話 |
|---|---|---|
| 邊界 | 來源分組是否等於目標，或整段落在目標內？ | 需要插補 → 最高 medium |
| 曲線跳變 | 發生率曲線在切點兩側有沒有變化？（`BREAK_CAPTURE_RATIO` 1.5 倍） | 曲線平坦 → low |
| **曲線單調** | 切點所在的官方組別是不是局部高峰／低谷？（`SHAPE_EXTREMUM_TOLERANCE` 10%） | 有極值 → low |

第三道是回測結論的直接實作。實測值：勞參率各組的翻轉幅度都在 0.5% 以下，
失業率在 20-24 歲翻轉 20.6% —— 所以公式 D 在該區間**自動標成 low**。

## 挑對來源等於白賺精度（`select_sources`）

同一個指標常有多個機關發布、分組粗細不同。引擎會自動挑：

| 來源 | 目標 18-24 | 目標 25-29 | 目標 30-35 |
|---|---|---|---|
| 主計總處（15-24 / 25-44） | 要切 | 要切 | 要切 |
| 內政部（五歲一組） | 切一刀 | ✅ **完全對上 → high** | 切一刀 |

`select_sources()` 同時解決了**重複計算**：先前同時傳入 25-29 與 25-44 時
兩筆都會被算進去（10 萬人變成 20 萬人）。現在重疊的來源只留成本最低的那筆。

## 已實作的公式

| 公式 | 用途 | 信心度 | 狀態 |
|---|---|---|---|
| exact_match | 分組邊界完全吻合 | high | ✅ |
| A (T1) | 加總型，人口權重 | low | ✅ |
| B (T2) | 加總型，有效母體加權 | medium | ✅ 主力 |
| C | 比率型，分子分母各自插補 | low（同權重時） | ✅ |
| D (T3) | 比率型，benchmark 校準 | medium | ✅ |
| LLM 語意判讀 | 非結構化年齡描述 | inferred | ⬜ 未做（§5.6） |

## 跟 Spec 的三處差異（建議回寫）

**1. 結構轉折的信心度降級改成條件式。**
§5.8 寫「切割點跨越結構轉折 → 低信心度」。那條規則是為 T1 寫的：T1 用總人口
當權重，看不見轉折，所以必須降級。T2 用的 r(a) 曲線如果本身就在轉折處跳變
（真實資料：17 歲 6.8% → 18 歲 15.7%，2.3 倍），轉折已經被吃進權重了，
再降一次等於對同一個問題懲罰兩次，會讓所有 18 歲切點的數字都變 low。
改成檢查 `r(a)` 在切點兩側的比值（門檻 1.5 倍，見 `BREAK_CAPTURE_RATIO`）。

**2. 比率型指標強制要求分子分母。**
`SourceRecord` 的 `numerator` / `denominator` 缺一就直接丟 `ValueError`。
ETL 抓失業率時**必須連同失業人數與勞動力人數一起抓**，否則公式 C/D 都做不了。

**3. §5.5「18–21 歲失業率約為 22–24 歲的 1.4 倍」沒有資料支持。**
接上真實資料後實測是 **1.00 倍**。原因是全國失業率也只公布到五歲組，
高峰整個落在 20-24 那一組（11.6%），組內的初次尋職效應觀測不到。
Demo 旁白已改成陳述真實形狀，不要照唸 1.4 倍 —— 評審可以當場查證。

## 已知限制

- r(a) 是**全國**曲線套到新北市。這正是公式 D 的邏輯（形狀外借、水準本地錨定），
  但要在 provenance 裡講明白。
- 15、16 歲的勞參率外推後被夾在 0%。組間加總不受影響（校準保證），
  只影響組內分布，而我們的切點都在 18 以上。
- 人口是**月底數**、勞動統計是**年平均**，兩者時點不同。
