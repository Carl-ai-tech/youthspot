## 驗證界線

- 世代人口差是推估訊號，仍受死亡、戶籍事件與口徑影響，不直接當作觀測的青年遷入遷出。
- OLS 驅動因子與相似地區是關聯分析，不能宣稱因果或下一個地區已被成功預測。
- 現行 forecast.py 使用 1.96 常態近似計算區間，小樣本可能低估不確定性。保留實驗標籤；不得宣稱已校準的95%涵蓋率。
