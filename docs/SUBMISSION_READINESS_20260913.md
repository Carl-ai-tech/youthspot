## 繳交前最優先三件事
1. 在簡報 Demo 頁補一張正式站實際畫面，標出「輸入問題 → 閱讀回答 → 點來源 → 看候選區 → 看限制／建議」。IMG_1413 明列簡報需含使用介面及操作流程；只放 URL 或現場口述不足以證明附件包含此項。
2. 用登出視窗實際播放影片連結、打開簡報與 GitHub。入口頁一處勾選「已測」另一處仍說「未測」，因此目前只能標未確認。核對交件平台要的是檔案還是連結、團員表單欄位，以及提交成功頁。
3. 凍結同一展示版本。時間緊可先使用已驗證 e564f1e，簡報／影片／現場同口徑；若改用新 master，必須重新驗證「典型移入區」流程並部署，不能只改版號。
